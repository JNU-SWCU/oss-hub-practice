# People Ownership

역할은 파일 소유권과 동일하지 않습니다. 제품 도메인이 확정되기 전에는
사람 이름으로 `features`나 `modules`를 만들지 않고, 역할별 의사결정과
검증 책임만 기록합니다.

| 역할 | 책임 | 승인할 결과 |
| --- | --- | --- |
| Designer: 진혜원 | 정보 구조와 사용자 흐름 | navigation, journey, flow, wireframe |
| Designer: 진솔 | 화면 상태와 재사용 UI | mockup, component inventory, accessibility |
| Tech Lead: 동규 (eaststar) | 통합 경계와 delivery | API adapter, CI/CD, security, rollback |
